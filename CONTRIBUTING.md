# Contributing to JustDrinks LTD Analysis

Thank you for considering a contribution. This is an analytics project, so contributions look a little different from a typical code repo.

## Ways to contribute

- **Improve the analysis.** If you spot a calculation that should be done differently, open an issue with the page name and the proposed change.
- **Add a new view.** New chart or page that surfaces something the existing dashboard misses? Fork the repository, add the page, and submit a pull request with a screenshot.
- **Sharpen the documentation.** If a sentence in the README or the PDF deck is unclear, ambiguous, or wrong, open an issue or a pull request with the rewrite.
- **Port to another tool.** Tableau, Looker or Excel rebuilds are welcome as separate branches with their own README in a `tableau/` or `excel-port/` folder.

## How to submit

1. Fork the repository
2. Create a branch named for your change (`add-margin-analysis`, `fix-target-calculation`)
3. Make the change in a copy of the Power BI project so the original is preserved
4. Update the README if the change affects the structure or the headline findings
5. Open a pull request with a clear description of what changed and why

## What gets accepted

- Changes that improve accuracy, clarity or coverage
- Documentation rewrites that make the work easier to understand
- New analytical views with a stated business question they answer

## What gets declined

- Cosmetic changes to report formatting that do not affect insight
- Changes that introduce external dependencies without discussion
